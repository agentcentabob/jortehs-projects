Train Set Checker

Every carriage on the Sydney Trains and NSW TrainLink network carries its own number, and every carriage belongs to a numbered set. This turns one into the other, both ways, and shows the working.

What the checker covers

Seven fleets, answered two different ways. Waratah, Waratah Series 2, Mariyung and OSCAR carriages carry their set number inside the carriage number, so the whole set can be worked back out from the numbering. Tangara, Millennium and K set carriages don't, and have to be looked up in a composition table instead — which is why the checker knows a fixed number of those sets and no others.

Ported from the standalone Python set checker in transport-shenanigans. Composition tables and numbering rules are held server side and answered by /api/set-checker — no Transport for NSW data is involved, so nothing here is live.
